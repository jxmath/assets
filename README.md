# assets

game files, thumbnails and `games.json` for [jxmath.github.io](https://github.com/jxmath/jxmath.github.io).

```
games.json            game list
g/<id>/index.html     each game (plus its own files)
images/thumbnails/    cover images
```

loaded by the site through `https://cdn.jsdelivr.net/gh/jxmath/assets@main/`.
